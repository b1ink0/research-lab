Which apps show WebP and AVIF in link previews?

Each link below is a page whose og:image and twitter:image is a different format. Share it in an app and see if the preview shows the image. Part of WordPress/performance#2760. Source and full results: github.com/b1ink0/research-lab.

Test pages

  • JPEG
  • PNG
  • WebP
  • AVIF
  • Transparent PNG
  • Transparent WebP
  • Transparent AVIF

Each image is 1200x630, a yellow circle with the format name. The transparent ones have no background, so a correct preview shows the app's own background around the circle. The email page shows all seven on a red background, to send as an HTML email.

Apps cache previews by URL. Add something new like ?v=2 to the page link to make the app read the page again. The image URL stays the same, so the app may still reuse an image it already fetched. For a fully fresh test, run npm run serve -w link-preview-formats from the repository behind a tunnel, which adds the same value to the image URL too.
